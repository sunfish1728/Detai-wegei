# 偉哲跑酷

地鐵跑酷風格的 3D 無盡跑酷小遊戲，主角換成小偉哲。純靜態網頁，不需要伺服器。

## 怎麼玩

- 直接用瀏覽器打開 `index.html` 就能玩（Three.js 跟角色圖都已經放在 repo 裡，不用網路）
- 也可以開 GitHub Pages，把整個資料夾當成靜態網站放上去

| 動作 | 電腦 | 手機 |
| --- | --- | --- |
| 換軌道 | ← → / A D | 左右滑 |
| 跳 | ↑ / W / 空白鍵 | 上滑 |
| 滾（空中按＝快速落地） | ↓ / S | 下滑 |
| 暫停 | P / Esc | 左上角按鈕 |

## 內容

- 4 個角色：原味偉哲、毒菇偉哲、黃牛偉哲、猛男偉哲
- 火車（有些會迎面開過來）、斜坡可以爬上車頂、低柵欄要跳、高柵欄要滾
- 從側面撞到火車會絆倒，站務員跟狗會追上來，5 秒內再絆倒一次就被抓
- 道具：🧲 磁鐵、👟 超級跳鞋（可以直接跳上火車）、🚀 噴射背包、✖️2 雙倍分數
- 最高分存在瀏覽器裡

## 檔案

- `index.html`：介面
- `js/game.js`：遊戲邏輯
- `js/assets.js`：角色圖片（去背後縮小，內嵌成 data URI，雙擊打開也能載入貼圖）
- `js/three.min.js`：Three.js r149
